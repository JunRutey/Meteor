# Meteor v1.3.1 · AI 不再限步，关于页更好找，打赏支持支付宝

v1.3.1 收尾了三处体验：AI 工具调用不再有固定步数/单轮调用数/累计字符预算，复杂问题可以一路查完；关于页不再堆一整篇介绍，而是把更新日志、项目仓库、讨论与问题反馈放在手边；打赏页重排为支付宝一键打赏与微信赞赏码两块。本版不改变任何数据格式。

## 新增

- **AI 工具调用不设固定上限**：移除 6 步、单轮最多 4 个、累计 24000 字符的预算。模型一次返回多少个工具调用就执行多少个，循环只在模型给出不含工具调用的回答时结束；`AgentResult` 仍记录实际步数与调用数。
- **关于页集中入口**：关于页改为应用名/版本 + 四行入口：更新日志、项目仓库、讨论、问题反馈。问题反馈二级页提供 GitHub 议题与邮箱反馈（JunRutey@outlook.com）。
- **两级更新日志**：点击「更新日志」先看到按最新在上的版本号列表；再点某个版本进入该版本的更新内容。版本列表与详情沿用关于页的返回箭头、标题与圆角卡片布局。
- **支付宝打赏**：打赏页新增「支付宝打赏」按钮，一键打开维护者的支付宝收款页；微信赞赏码保留，居中限宽显示。

## 修复

- 修复关于页把长篇介绍与更新日志挤在一起、想找仓库或反馈入口时不好找的问题。
- 修复打赏页一张大图从上到下铺满、缺少操作层次的问题。

## 变更

- **关于页不再显示介绍正文**：`about.md` 不再渲染；关于页只保留必要身份信息与可点击入口。
- **设置里的关于区**：保留 Meteor 版本入口与打赏；更新日志入口移入关于页，避免同一功能出现两遍。
- **AI 错误文案**：移除「工具调用次数达到上限」错误；单条工具结果仍按 2500 字截断，避免一条超大记录撑爆上下文。
- **打赏页排版**：支付宝说明 + 主按钮，微信说明 + 居中赞赏码，底部说明「打赏是自愿支持，不会解锁任何功能或数据」。

## 已知限制

- 不改变数据格式；旧日记、备份、人物档案、AI 会话与已保存的出生日期继续可用。
- AI 循环没有固定轮数兜底，复杂问题可能持续较久并产生更多 API 费用；当前没有独立「停止生成」按钮，退出对话页或应用会取消请求。
- 单条工具结果仍截断到 2500 字；需要完整正文时模型应分次读取。
- 更新日志版本列表按 `changelog.md` 中 `## v...` 的顺序展示，发布时需保证最新版本在最前；详情页只做轻量 Markdown 行渲染，不显示图片或表格。
- 支付宝打赏通过外部链接打开，能否直接唤起支付宝取决于设备上安装的应用与浏览器；打赏是自愿支持，不改变任何功能或数据权限。
- 问题反馈通过 GitHub 议题或邮件进入，应用内不会自动附带日志、设备信息或档案内容。
