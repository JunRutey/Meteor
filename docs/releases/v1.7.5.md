# Meteor v1.7.5 · 1.7.4 的紧急修复

v1.7.5 是 [v1.7.4](https://github.com/JunRutey/Meteor/releases/tag/v1.7.4) 的紧急修复版。
1.7.4 的界面改版上线后发现三个问题：隐藏状态栏时侧边栏底部会露出一条主页内容，
主题与文件选择器的下拉菜单圆角过小，选项下面的说明文字也偏啰嗦。本版只修这三处，
不改档案数据、备份快照、密钥与通知渠道。

## 修复

- **侧边栏底部露底**：1.7.4 让侧边栏全屏绘制时只向上补了状态栏区域，底边仍停在安全区上方。
  隐藏状态栏后，面板底边与屏幕底部之间露出一条主页底栏，「Meteor v1.7.4」下方的圆角也
  像被切了一刀。现在侧边栏与遮罩一起铺满整个窗口，直到屏幕最底部；标题、功能列表与
  「设置」入口仍留在手势条与刘海之外，不会被系统栏压住。
- **下拉菜单圆角过方**：1.7.4 的主题与文件选择器菜单沿用了 Material 默认的 4dp 圆角，
  和周围 20–24dp 的卡片放在一起显得很硬。本版把菜单圆角改为 22dp。
- **选项说明太啰嗦**：主题菜单不再显示「跟随系统深色或浅色外观」等三行说明，只保留
  选项名；文件选择器的说明精简为「保留拍摄时间等源数据」与「元数据由系统决定」。

## 变更

- **版本号使用 1.7.5，而不是 1.7.4.1**：应用内更新只识别三段式版本号，遇到 `v1.7.4.1`
  这类四段标签会把 Release 判为无效，已安装的 1.7.4 检查更新会直接报错。改用 1.7.5
  才能让 1.7.4 用户正常收到这次紧急修复。

## 已知限制

- 隐藏状态栏后，侧边栏的背景仍绘制到屏幕最顶端；面板内容会自动避开状态栏与刘海，
  主页顶部内容保持原来的安全距离。从屏幕顶部下滑仍可临时唤出状态栏。
- 侧边栏的底部圆角现在落在屏幕右下角；手势条区域由面板背景覆盖，内容不进入该区域。
- 本次不改变档案数据格式，也不修改备份、密钥或通知渠道设置。
