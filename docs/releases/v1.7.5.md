# Meteor v1.7.5 · 侧边栏自定义与界面细节修复

v1.7.5 是 [v1.7.4](https://github.com/JunRutey/Meteor/releases/tag/v1.7.4) 之后的修复版。
这一版把侧边栏的显示与排序挪进抽屉本身：长按功能即可隐藏、排序或管理；同时修掉侧边栏
底部露底、被拉成全屏、向下拖动回跳等问题，并精简了下拉菜单与通知页的文案。不改档案
数据、备份快照、密钥与通知渠道。

## 新增

- **侧边栏内自定义**：长按任意功能，弹出「隐藏 / 排序 / 管理功能」菜单。设置入口固定在
  底部，不参与排序或隐藏。
- **拖动排序**：选「排序」后头部变为对勾，每行出现拖拽把手；按住上下拖动即可调整顺序，
  上下两个方向对称，松手保存，点对勾或按返回键退出。
- **管理功能**：一个带勾选框的弹窗，勾选要显示的功能，点「确定」后生效，「取消」不改动
  原样。全部隐藏时列表里会给出「管理功能」入口兜底。

## 修复

- **侧边栏底部露底**：面板底边原先停在安全区上方，隐藏状态栏时下方会露出一条主页底栏。
  现在面板与遮罩一直铺到窗口最底部，内容仍避让手势条与刘海。
- **侧边栏被拉成全屏**：一次改动里给面板和遮罩都强制了窗口宽高，导致 300dp 的抽屉被拉伸
  铺满整屏。现在遮罩铺满窗口，面板只补足高度，宽度恢复为 300dp。
- **向下拖动回跳**：拖动时目标位置与当前顺序取自不同快照，导致向下滑一点就弹回上面。
  现在两者取自同一份顺序，按手指相对抓取点的位移计算目标槽位，滑动跟手、不再回跳。
- **隐藏状态栏时的顶部接缝**：原先抽屉顶部的圆角和阴影会在白色顶栏上画出一道痕迹。现在
  隐藏状态栏时抽屉顶边改为直角、不投影阴影，直接与顶栏接壤；状态栏可见时仍保留圆角与阴影。
- **下拉菜单圆角过方**：主题与文件选择器的菜单圆角从 Material 默认的 4dp 改为 22dp，
  与周围的 20–24dp 卡片统一。
- **选项说明太啰嗦**：主题菜单不再显示三行说明小字；文件选择器的说明精简为「保留拍摄时间
  等源数据」与「元数据由系统决定」。

## 变更

- **移除设置里的「自定义侧边栏」二级页**：侧边栏现在是自己的编辑器，不必再进设置调整。
- **通知页文案精简**：日记提醒、问题提醒与更新下载通知只保留时间与作用，去掉「悬浮显示」
  「系统通知铃声」等实现细节；权限与精确闹钟提示缩短，操作按钮与说明左对齐。
- **版本号使用 1.7.5，而不是 1.7.4.1**：应用内更新只识别三段式版本号，遇到 `v1.7.4.1`
  这类四段标签会把 Release 判为无效，已安装的 1.7.4 检查更新会直接报错。改用 1.7.5
  才能让 1.7.4 用户正常收到这次修复。

## 已知限制

- 侧边栏顶部从状态栏下方开始，底部贴到窗口最底部；带刘海或挖孔的设备上，内容会自动避开
  前摄开孔。从屏幕顶部下滑仍可临时唤出状态栏。
- 更新签名校验要求下载包与当前安装使用同一证书；自行重签名的安装包无法通过，需先卸载或
  手动安装。
- 本次不改变档案数据格式，也不修改备份、密钥或通知渠道设置。
