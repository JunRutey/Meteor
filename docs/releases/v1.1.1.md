# Meteor v1.1.1 · 搜索更懂中文，应用锁不再把人挡在门外

v1.1.1 是一个以检索打磨和问题修复为主的补丁版：搜索开始支持单个汉字与心情标签，结果能直接
跳回对应日期；应用锁在没有指纹/人脸的设备上回退到锁屏密码，完全没有锁屏凭据时也会给出
需要确认的关闭入口，不再有把自己锁死的可能。生辰页背景与出生日期显示的两处小问题一并修掉。
本版不改变数据格式，旧日记、备份、人物档案、AI 会话与已保存的出生日期继续可用。

## 新增

- **单字也能搜到**：中文按重叠二元词建索引，以前输入单个汉字（例如「心」）搜不到「心情」；
  现在单个汉字会退到子串匹配，短查询同样有结果。
- **心情可以按标签搜索**：心情记录会以界面上的文字（开心、平静、疲惫……）进入索引，搜索
  「开心」就能找到对应日期；点开结果会回到日历并定位到那一天，而不是停在搜索页。
- **新记录即时可搜**：刚记下的心情会立刻更新索引，不必等到下次启动重建。

## 修复

- **应用锁不再把人锁死在门外**：设备没有录入指纹或人脸时，改用锁屏 PIN、图案或密码验证；
  设备完全没有锁屏凭据时，解锁页会说明原因，并提供「去系统设置」与需要二次确认的
  「关闭应用锁」，避免档案被永久挡住。
- 修复生辰页背景不跟随动态取色（Material You）的问题。
- 修复出生日期农历换算期间，下方公历日期文字会闪空的问题。

## 变更

- **搜索打开日记改为只读预览**：与日历里查看日记的行为一致，需要修改时再进入编辑页，
  避免误触直接改到正文。
- **应用锁说明文案**：改为「用生物识别或锁屏密码解锁」，与实际验证方式一致。
- **首页标签页状态**：由首页持有而非页面内部临时状态，从搜索返回时不会被重置，
  搜索跳回也能直接切到日记标签。

## 已知限制

- 不改变数据格式；旧日记、备份、人物档案、AI 会话与已保存的出生日期继续可用。
- 应用锁是进入应用的界面门禁，不是加密边界：文件密钥不绑定生物识别，能通过系统验证就能
  看到档案内容。
- 设备既没有锁屏密码/图案也没有录入生物识别时无法开启应用锁；已开启的会给出需要确认的
  关闭入口。
- 单字查询走子串匹配，档案体量很大时可能比多字查询稍慢，命中范围也更宽。
- 心情标签检索依赖索引重建：旧的心情记录会在启动重建索引之后才能被搜到。
- 自动更新只认 GitHub 正式 Release；安装仍需允许「安装未知来源应用」并由系统安装器确认，
  部分设备或安全软件会拦截。
