# Meteor v1.5.2 · 写日记提醒改到晚上

v1.5.2 只改一件事：**每日写日记提醒的随机窗口从上午 8:00–9:00 挪到晚上 20:00–21:00**。

原来的提醒在一天刚开始时到达，那时多数人还没什么可记，提醒容易被当成打扰直接划掉。
晚上睡前才是回顾当天、真正要动笔的时刻，提醒与使用场景对齐；通知正文里
「距今天结束还有 x 小时」在晚上读也更自然（上午发是 16 小时，现在 20:00 发是 4 小时）。

本版不改变任何数据格式：旧日记、旧备份、人物档案、媒体、AI 会话与已保存的出生日期继续可用，
也没有新增或迁移任何设置项。

## 新增

无。本版没有新增功能。

## 修复

无。本版没有修复缺陷。

## 变更

**写日记提醒改到晚上 20:00–21:00**

- 每天仍然只提醒一次，仍是在窗口内随机一个整分钟，发出后记录当天日期、当天不再重复。
- 窗口从 8:00–9:00 整段挪到 20:00–21:00，随机的「不可预期性」保持不变。
- 通知标题仍是「你写日记了吗？」，正文仍是「距今天结束还有 x 小时，时间正沿着星河向前，
  愿你记录下美好。」；x 按发送时刻到当天 24:00 的整小时数向下取整，所以现在
  20:00 发是 4 小时、20:30 之后是 3 小时。
- 设置页通知区副标题、系统通知渠道说明、首次启动引导页的权限说明，文字里的时间一并改为
  20:00–21:00；精确闹钟未授权时的提示改为「可能晚于 21:00」。
- **提醒开关没有变化**：仍然只有设置里那一个「通知总开关」，同时控制更新下载通知与每日提醒；
  本版没有时间选择器，也没有新增可配置项。

## 已知限制

- 提醒窗口固定，不能自定义。想换个时间目前只能等后续版本，或者直接关掉通知总开关。
- 关闭通知总开关会连同更新下载通知一起关闭（这是「总开关」的既有取舍，本版未改）。
- 精确闹钟未授权的设备上提醒以非精确方式触发，可能晚于 21:00；设置页保留授权入口。
- x 为整小时向下取整，最多有不到 1 小时的误差。
- 已安装的旧版本升级后，闹钟会在系统发出「应用已更新」广播时按新窗口重排，正常情况下
  不会出现「升级后又按上午时间提醒一次」；若通知权限或日记提醒渠道处于关闭状态，
  本次本就不会发通知。
- 每日提醒与是否已写日记无关：当天已经写过日记，仍会收到一条提醒。
