# Meteor v0.9.1 · 紧急修复：隐藏图标后的找回路径

## 新增

- 本版是 v0.9.0 的紧急修复版本，没有新增功能。

## 修复

- **隐藏桌面图标后拨号唤不回应用**：Android 10 起，后台广播接收器启动界面需要「后台启动」豁免，
  否则系统会静默丢弃这次启动——`startActivity` 不报错，界面却不会出现。
  v0.9.0 及更早版本没有声明任何豁免，所以在原生 / 类原生系统上，隐藏图标后暗号本来就无法生效；
  小米 / 澎湃则由「后台弹出界面」单独把关。现在：
  - 声明「显示在其他应用上层」（`SYSTEM_ALERT_WINDOW`）作为 Android 公开的后台启动豁免；
  - 小米 / 澎湃会读取「后台弹出界面」状态，并提供直达授权页的入口；
  - **隐藏前必须先用暗号真正唤回一次应用**，确认「拨号盘会派发」与「系统允许后台启动」两步都成立，
    才允许打开隐藏开关，不再只靠一句警告。
- **升级把用户锁在门外**：应用更新可能重置厂商的「后台弹出界面」授权。
  现在更新后会重新检查回退路径；如果图标仍隐藏、又无法确认暗号可以唤回，
  会自动恢复图标并关闭隐藏开关。读不到状态（`UNKNOWN`）也按「不可证明」处理，
  宁可图标重新出现一次，也不让用户进不来。
  **已经因 v0.9.0 隐藏图标而进不去的用户**：从本 Release 页面下载 APK 手动安装即可，
  安装完成后图标会自动恢复；不需要卸载，本地数据不受影响。
- **每日提醒的通知状态误判**：应用通知总开关开着、但「日记提醒」通知渠道被单独关闭时，
  设置页原先仍显示提醒可用，实际却不会通知。现在分别检查应用通知权限与提醒渠道，
  渠道关闭时给出说明，并可直接跳到该渠道的设置页。

## 变更

- 新增「显示在其他应用上层」特殊权限。它只用于取得 Android 的后台启动豁免，
  Meteor 不绘制任何悬浮窗；在非小米设备上不授权时，隐藏图标的入口会被拦下，因为那条路本来就走不通。
- 隐藏图标的确认框会显示回退路径状态（可用 / 被拦截 / 无法确认），
  并在未通过暗号实测前禁用「隐藏」按钮。
- 每日提醒的设置说明区分「通知总开关」与「日记提醒渠道」，不再笼统提示「通知权限未开启」。

## 已知限制

- 拨号盘是否派发 `*#*#314159#*#*` 由系统和拨号器决定；部分三星机型和深度定制拨号器仍可能拦截，
  无法从应用侧保证。
- 对 Meteor 执行「强制停止」后，暗号仍然无效：被停止的应用收不到系统广播。
  此时只能重新打开应用，或重装（会丢失本地数据）。
- 小米 / 澎湃的「后台弹出界面」是私有 AppOp，系统更新后可能读取失败；读取失败时只显示「无法确认」，
  需要用户实际拨号验证，应用不会误报「可用」。
- 暗号实测记录只在当前进程内 10 分钟内有效；应用被系统回收后需要重新测试一次。
- 隐藏图标后，自动检查更新仍需要应用能启动；已经完全无法进入的用户请手动下载本版 APK。
- 隐藏图标状态不参与备份，换机或重装后图标默认显示。
