# Meteor v0.7.3 · 思考与工具调用合成一组，输入框可收起

## 变更

- **思考与工具调用合并成一组**：每条回答上方只有一个折叠块「思考与工具调用（n）」。
  展开后按发生顺序列出：可单独展开的「思考过程」段落，以及每一次工具调用
  （名称、参数摘要、✓/… 状态、结果首行）。答完默认收起，随时可以再展开。
- **顶部栏改为固定**：标题与「清空」「返回」常驻；只有「技能」和「对话对象」两排选择器
  会随向上浏览收起，往回滑一点就立刻展开，把空间留给对话。
- **输入区可以收起**：输入框右侧的「收起输入」把它折成一行，只留「展开输入」，
  需要更多阅读空间时不必被输入框挤着。
- **说明文字精简**：输入框下原来两行（发送说明 + 隐私与加密说明）压成一行
  「内容会发送到 DeepSeek」；同意流程与「关于」页里的隐私说明保持不变。

## 修复

- 上一版把思考过程与工具调用拆成两个平级区块，且工具**结果**没有显示；
  现在合成一组，并把每次调用的输出首行带出来，结束后仍可回看。

## 已知限制

- 工具结果只显示第一行、最多 120 字；完整输出不在界面上。
- 过程信息与对话正文一样只在本次打开期间保留，重启后恢复的加密历史只有问答正文。
- 折叠状态不跨消息记忆：重新进入会话时各过程组默认收起。
- 工具调用很多时，展开这一组会占据较长篇幅，可整体收起。
