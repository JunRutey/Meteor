# Meteor v0.9.4 · 按设计稿重做界面

## 新增

- **搜索筛选**：搜索页新增「全部 / 日记 / 心情 / 档案」四个筛选；
  当前筛选没有结果时会提示换关键词或切回「全部」。
- **日历本月概览**：月份标题改为「2026 年 11 月」，新增「今天」按钮
  （必要时自动切回本月），并显示「本月已记录 X 天 · 已连续 Y 天」。
  日期标题带星期，今天的心情显示为「今日心情 · 开心」。
- **日记页头与编辑体验**：编辑页页头显示「11 月 8 日 · 周六」，预览按钮移到页头胶囊；
  正文下方显示字数与「仅保存在本机」；保存按钮改为 52dp 胶囊。
- **生辰页进度**：新增「这一岁已走过 X%」进度条，倒计时拆成天 / 时 / 分 / 秒四块，
  年龄与下次生日的排版重做。
- **新应用图标**：自适应图标背景改为白色，前景图标同步更新。

## 修复

- 本版没有用户可感知的缺陷修复，主要是界面与视觉重做。

## 变更

- **整体视觉**：纸蓝底 `#F4F8FC`、石板蓝强调 `#426989 / #2E4F6B`、白色卡片、
  发丝线 `#D3E1EE`；卡片与输入框使用更大的统一圆角，按钮统一为 48 / 52dp 胶囊。
- **底部导航**：高度改为 72dp，选中项改为 56×28 胶囊加主题色图标，
  取消了原先图标上下浮动的动画。
- **设置页**：顶部新增返回箭头；分组重排为
  「外观 / 个人资料 / 安全与隐私 / AI / 通知 / 备份与数据 / 应用更新 / 诊断 / 关于」；
  说明文字精简；更新已下载时显示「新版本已就绪」卡片。
- **首页 / 日历 / 搜索 / 生辰 / 日记**：按设计稿统一间距、控件与文案；
  首页为 AI 入口留出底部空间。
- **编辑器**：工具栏只保留链接与图片，预览入口移到页头；
  正文改为 17sp / 26sp 行高、20dp 圆角与主题色描边。
- **备份与日志**：导出、导入、导出日志按钮统一为 48dp 胶囊。

## 已知限制

- 本版不改变数据格式；旧日记、备份、出生日期与应用锁设置继续可用。
- 搜索筛选只过滤当前关键词的结果，不会扩大搜索范围。
- 动态取色默认仍关闭；开启 Material You 后会覆盖纸蓝 / 石板蓝配色。
- 「存储诊断」入口仍只在调试版显示；正式版的「诊断」分组只有调试日志开关。
- 新图标为白底，在深色桌面或部分启动器上可能显示为白色圆角方块。
- 底部导航选中态改为固定胶囊，不再有图标上下浮动动画。
