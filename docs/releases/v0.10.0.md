# Meteor v0.10.0 · AI 联网、文件输入与加密多会话

## 新增

- **DeepSeek 联网模式**：AI 对话可切换到联网模式，使用官方
  `deepseek_web_search` 与 `deepseek_read_url` 搜索网页、阅读链接，并在回答下方展示
  引用来源；搜索、打开网页、页内查找等过程会显示在「思考/工具」区域。
  联网模式不调用本机档案工具，只附带少量本地预取片段，不开放命令执行、任意文件、
  密钥或备份操作。
- **文档与图片输入**：可主动选择支持的文档或图片，上传到官方 DeepSeek `/files` 接口解析，
  再随问题一起发送给 `deepseek-flash`。上传与解析可能产生费用；文件默认 30 天后过期，
  删除会话时会尝试从 DeepSeek 远端删除。
- **加密多会话**：AI 对话按「技能 + 对话对象」分成独立会话，保存在
  `数字遗产/AI对话/sessions/`，使用与日记相同的 AES-256-GCM 密钥加密。
  支持新建、切换、重命名、删除会话，也支持编辑提问、重新生成和继续生成。
- **附件生命周期**：记录每个附件的上传时间；历史请求只重发未过期的附件，
  单条消息最多 10 个附件、单次请求最多 20 个文档引用；编辑或重新生成丢弃后续消息时，
  会尝试清理这些消息中的远端附件。
- **更可靠的会话读取**：单个会话无法解密或解析时只跳过该会话，不再影响其他对话；
  会话写入使用临时文件原子替换；会话按 scope 建立索引，切换技能或人物时不再重复解密全部会话。

## 修复

- 修复会话列表遇到一个坏文件就整体不可用的问题。
- 修复会话保存、重命名、切换、恢复之间的竞态，避免旧快照覆盖新状态。
- 修复编辑或重新生成后，被丢弃消息的远端附件长期残留的问题。
- 修复切换 DeepSeek 模型后无法删除远端文件的问题。
- 修复历史附件过期后仍被重发、导致后续请求失败的问题。
- 修复 `finish_reason=content_filter` 被显示成普通空回复的问题。
- 修复 AI 返回的引用链接可能打开非 HTTP(S) 地址的问题。
- 修复重命名会话确认按钮显示「发送」的问题。

## 变更

- **默认模型改为 `deepseek-flash`**。旧版本中手动选择过 `deepseek-chat` 的用户会保留原选择；
  如需联网或文件输入，请在设置中切换到 `deepseek-flash`。
- **AI 对话格式升级**：旧版行式聊天记录会在首次读取时迁移为加密会话文件；迁移失败或密钥失效时，
  单个会话会被跳过，其他记录仍可读取。
- **联网与文件输入仅支持官方 DeepSeek 接口**，且只对 `deepseek-flash` 开放；
  OpenAI、自定义兼容接口和其他 DeepSeek 模型仍可使用本机档案工具与普通对话。
- **联网模式与本机工具分离**：联网模式只使用服务端联网工具，不执行本机档案工具；
  需要档案检索、写日记或人物操作时请切回「档案工具」模式。
- **附件上传改为流式发送**：选中的文件先写入应用缓存临时文件，再从临时文件流式上传，
  完成后立即删除，避免 100 MiB 文档整体占用内存。
- 文件输入支持 PDF、Word、PowerPoint、Excel、图片、纯文本、Markdown、CSV、JSON、
  EPUB、MOBI 与常见代码/文本文件；具体类型和大小上限由 DeepSeek Files API 决定。
- **隐私说明更新**：开启联网或文件输入后，问题、相关档案片段以及你主动选择的文件会通过 HTTPS
  直接发送到你配置的 AI 提供商；上传与解析可能产生费用。Meteor 没有自建后端，不接收、
  不收集、不记录应用内容。

## 已知限制

- AI 默认关闭，需要自备 API Key；开启前会提示内容会离开设备。
- 联网搜索、阅读链接和文件输入目前仅支持官方 DeepSeek 接口与 `deepseek-flash`。
- 联网模式不能调用本机档案工具，只能使用少量本地预取片段；需要工具链时请使用档案模式。
- 思考档位开启时，`deepseek_web_search` 会走深度思考搜索，可能发起多次搜索/打开网页并产生额外费用；
  需要普通联网搜索时请在设置中把思考档位设为「关闭」。
- 文件默认 30 天后过期；删除会话时的远端删除是尽力而为，失败的文件会在 30 天后由服务端清理。
  原文件、解析结果均无法从 DeepSeek 下载。
- 历史消息中超过 30 天的附件不会在后续请求中重发，避免过期 `file_id` 导致整轮失败。
- 会话标题由本机根据首条提问生成；服务端标题接口当前未启用。
- 加密会话依赖设备 Keystore；换机后旧密钥不可恢复，请通过明文备份恢复档案。
- 不开放任意命令执行、任意文件系统访问、密钥导出、备份导出或导入等能力。
