# Meteor v0.7.2 · 对话过程可回看，输入栏会收起

## 修复

- **回答里冒出一大片 "null"**：模型发出工具调用时，流式分片里的 `content` 是 JSON null，
  解析时把它当成字符串拼进了回答，一段工具调用下来就是几十上百个 "null"。
  现在把 JSON null 当作「这一段没有内容」，`reasoning_content` 同样处理，并补了回归测试。
- **思考过程与工具调用一结束就消失**：它们原本只存在于「正在回答」的临时状态里，
  回答一到就被清空，之后没有任何入口能再看。现在随消息一起保留，
  折叠成「思考过程」与「工具调用（n）」两个可展开区块，随时能重新打开。

## 变更

- **顶部栏跟着聊天一起收起**：标题、技能与对话对象选择器改为随内容滚动，
  往下翻时自动收起，滚回顶部再出现；收起后顶部会浮出一条紧凑栏，
  「清空」「返回」始终点得到。

## 已知限制

- 思考过程与工具调用只在当前打开期间保留；应用重启后恢复的加密历史仍只有问答正文
  （历史文件格式没有改动，也就没有为此做迁移）。
- 过程区块默认收起，展开状态不跨消息记忆。
- 流式过程中新内容仍会把你带回列表底部；想慢慢读旧消息，等这一轮答完再向上翻。
