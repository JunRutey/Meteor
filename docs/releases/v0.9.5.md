# Meteor v0.9.5 · 移除隐藏图标，统一卡片视觉，启用 R8

## 新增

- 本版没有新增功能。

## 修复

- **生日页阴历切换闪烁**：切换阴历的年 / 月 / 日时，保存按钮与「请选择生日」
  提示不再短暂闪动；转换结果越界时会显示提示，不再静默失效。

## 变更

- **移除「隐藏桌面图标」与拨号暗码**：找回入口同时依赖系统拨号盘是否派发暗号、
  系统 / 厂商是否允许后台启动，两者都无法在隐藏图标之前被可靠验证；一旦暗号被
  系统静默丢弃，用户没有自救手段，风险不可控，因此整体移除。升级后桌面图标会
  自动回到桌面，旧偏好不再读取；之前隐藏图标时创建的桌面快捷方式会失效。
- **卡片视觉统一**：人物列表与详情、聊天记录、相册、人格页、AI 对话、首启引导、
  生日设置页改为白卡片 + 发丝线 + 大圆角；人格页操作按钮可横向滑动，窄屏不再
  裁切；人员列表卡片补上水平内边距，与其它页面一致。
- **发布包启用 R8**：release 构建开启代码与资源压缩，安装包更小；release 崩溃
  日志保留行号。

## 已知限制

- 不改变数据格式，旧日记、备份、出生日期与应用锁设置继续可用。
- 旧版本留下的 `hide_launcher_icon` 偏好仍残留在本机 DataStore 中，但不再读取。
- R8 混淆后 release 堆栈只保留行号，类 / 方法名会被重命名；完整符号需要
  `mapping.txt`（本版未随 Release 上传）。
- 动态取色默认关闭；开启 Material You 后会覆盖新配色。
- 存储诊断入口仍只在调试版显示。
