# Meteor v1.3.0 · 一个通知总开关，备份不再漏掉出生日期

v1.3.0 把通知收成一个总开关，并把每日提醒固定到 8:00–9:00 的随机时刻；备份与数据也补上了此前遗漏的出生日期和设置。本版不会改变既有档案格式：旧日记、备份、人物档案、AI 会话与出生日期继续可用，旧通知设置会自动迁移。

## 新增

- **通知总开关**：设置里只剩一个「通知总开关」，同时控制应用内更新下载通知与每日写日记提醒。关闭后不再弹下载进度，也会取消待发送的提醒；打开后两类通知一起恢复。
- **每日 8:00–9:00 随机提醒**：每天在本地 8:00–9:00 之间随机一个时刻发送一次，不再要求你手动选时间。通知大字为「你写日记了吗？」，小字为「距今天结束还有 x 小时，时间正沿着星河向前，愿你记录下美好。」；x 在发送时按当天剩余整小时计算（例如 08:30 发送时显示 15 小时）。
- **备份覆盖出生日期**：出生日期从应用私有目录迁入档案目录，随明文备份一起导出，换机导入后按新设备密钥重新加密。旧位置会在首次读取或备份时安全迁移，失败时保留旧文件作为回退。
- **备份覆盖设置**：备份 zip 增加加密的设置快照，包含主题、通知总开关、人物自定义标签、AI 非密钥配置、累计用量与引导状态。API Key、应用锁、禁止截屏与 AI 同意不会进入备份。

## 修复

- 修复备份只覆盖档案目录、漏掉出生日期与设置的问题。
- 修复每日提醒依赖手动选择时间、且在同一天重启后可能重复发送的问题。

## 变更

- **提醒时间不再可配**：移除设置里的提醒时间选择器与细分项；改为 8:00–9:00 随机，并在发送成功后记录当天日期，避免同一天重复提醒。
- **不再按是否已写日记跳过**：每日提醒按需求每天发送一次，不再因为当天已经写过日记而静默跳过。
- **提醒文案**：通知正文改为「距今天结束还有 x 小时，时间正沿着星河向前，愿你记录下美好。」，并使用展开样式完整显示。
- **通知迁移**：升级时读取旧的「每日写日记提醒」开关作为总开关初值；旧开关显式关闭的用户保持关闭（更新下载通知也会一起关闭，可手动打开）。
- **出生日期路径**：新路径为档案目录内的 `记忆档案/自己/birth_profile.bin`；旧备份仍可导入，新备份导入旧版本客户端不会损坏数据，但旧客户端不会读取出生日期或设置快照。
- **备份导入**：设置快照在导入成功后恢复；旧备份没有快照时保持本机设置不变。

## 已知限制

- 不改变档案数据格式；旧日记、备份、人物档案、AI 会话与已保存的出生日期继续可用。
- 非精确闹钟设备上提醒可能晚于 9:00；设置页保留精确闹钟授权入口与说明。
- 通知总开关关闭时，更新下载通知也不会显示；更新本身仍会继续，可在「设置 → 应用更新」查看状态。
- 备份中的设置快照不包含 API Key、应用锁、禁止截屏、AI 同意与最近提醒发送日期；换机后需要重新填 Key、开锁屏保护并重新同意 AI。
- 新备份导入旧版本客户端时，出生日期与设置快照不会被旧客户端识别；旧备份导入新客户端时这两项为 no-op。
- x 为整小时向下取整，可能有不到 1 小时的误差；提醒只在 8:00–9:00 窗口内触发。
- 自动备份的既有调用时机未改；本次只保证备份覆盖范围完整，没有新增定时调度。
