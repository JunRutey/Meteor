# Meteor v1.7.0 · 每日一问按天用，首页有了侧边栏

v1.7.0 的主线是**把每日一问从「能写」做成「像日记一样按天用」**，同时给首页加了一层功能总入口。

v1.6.0 把每日一问做出来了，但界面把「浏览、提问、回答」三件事挤在两屏里：列表页顶上永远挂着
提问表单，详情页把提醒、编辑器、回答堆成一列，从通知点进来还会被直接塞进编辑器。时间选择用的
是系统对话框，和应用里唯一的另一处日期选择（生辰页的滚轮）也不一致。

本版把这三件事分开：**列表只负责浏览，提问是独立页面，详情永远先阅读、再决定要不要回答。**
时间选择统一为生辰页同款的五列滚轮。日卡片的「每日一问」也从「打开全部问题的总览」改成
**按选中的那一天进入**：那天已经问过就打开那道题，没问过就带着日期新建，可以补写过去某天。

同版还新增了**首页侧边栏**：点页头「Meteor」展开功能列表（每日一问总览、相册、人际关系、
AI 对话、搜索、设置），首页原有的快捷入口、AI 悬浮按钮与搜索 / 设置图标全部保留。

1.6.1 的**更新弹窗与镜像择优下载**也包含在本版中。本版**不迁移任何既有数据**：
旧问题与回答照常打开，备份、加密与索引格式不变。

## 新增

**每日一问**

- **提问独立成页**：从列表的「＋」或空态按钮进入。正文输入框占主要区域，提醒以可删除的 chip
  横排在下方；默认提醒仍是「明天同一时刻」，也可以只保存问题不提醒。
- **统一的滚轮时间选择**：年 / 月 / 日 / 时 / 分五列，与生辰页的外观和交互一致；拖动只预览，
  **点某一行才选中**，早于当前时刻会判为非法并禁用「确定」。
- **按天归档**：问题新增「归档日」概念。日卡片左下角的「每日一问」按选中的日期进入——
  那天已有问题就打开那道题，没有就带着日期新建，提问页顶部显示「为 x月x日 提问」。
  补写的问题归到那一天，但仍然记录真正写下的时刻。
- **首页侧边栏**：点页头「Meteor」（右侧有向下小箭头）打开左侧抽屉，集中放每日一问总览、
  相册、人际关系、AI 对话（开启时）、搜索与设置；底部显示当前版本号。点遮罩、右上角 × 或
  系统返回键关闭。
- **回答编辑器支持插入链接**。

## 修复

- 回答编辑器工具栏里的「链接」按钮此前点确认后没有任何反应，现在可以正常插入链接。
- 回答编辑器暂时隐藏了「图片」按钮：回答还没有媒体导入链路，留一个按了没反应的按钮比暂时
  没有按钮更糟。

## 变更

**每日一问界面**

- 列表页不再固定展示提问表单，只保留筛选胶囊（全部 / 待回答 / 已回答，各带数量）与卡片；
  删除收进卡片右上角的「⋯」菜单，不再紧挨正文常驻。
- 详情页**永远先进入阅读形态**：问题卡、提醒、回答列表，「回答 / 再回答一次」固定钉在底部。
  从列表、从通知、从历史点进来都是同一个页面，不再被自动弹进编辑器。
- 回答形态整屏是编辑器，编辑模式里返回会先确认未保存的草稿，系统返回键走同一条路径；
  保存回答后自动滚到最新一条。
- 问题与回答的存储格式新增可选字段 `askedOn`，**版本号仍为 1**：旧文件没有该字段时按
  `createdAt` 在设备时区派生，旧客户端读新文件也能照常显示，只是看不到归档日。
- 已开启「减少动效」时，侧边栏与遮罩直接出现，不做滑入 / 淡入。

**更新与首页（1.6.1 起）**

- 发现新版本先弹窗询问：「立即更新 / 稍后再说 / 忽略此版本」；下载前在官方地址与三个内置
  镜像间按延迟择优，并用官方 SHA-256 校验下载结果。
- 日卡片左按钮为「每日一问」，底部快捷入口为「相册 / 人际关系」两格；看某天的图片从相册进。

## 已知限制

- 同一天可以有多条问题，但日历日卡片只打开最新创建的一条；其余请在侧边栏的「每日一问」总览里看。
- 「待回答 / 已回答」按有没有回答过划分：已回答但后来又加了提醒的问题，仍会显示下次提醒。
- 补写的旧问题按 `createdAt` 派生归档日时使用的是设备当前时区，跨时区旅行可能让很旧的问题
  落到相邻一天；本版之后新写的问题记录明确的日期，不受时区影响。
- 未来日期没有日卡片按钮，因此不能给未来补写问题。
- 回答编辑器目前不能插图；插入链接已可用。
- 侧边栏与首页快捷入口的入口有重复，这是刻意保留的：常用动作仍一步可达。
- 每日一问的界面没有自动化 UI 测试覆盖；存储与提醒策略有单元测试。
- 社区镜像的可用性不由我们控制，全部失效时退化为直连；内置镜像清单要更新就得发版。
- 「忽略此版本」是设备本地状态，换机或清除数据后会重新询问，也不进备份。
- 安装仍需允许 Meteor 安装未知来源应用，并由系统安装器确认。
