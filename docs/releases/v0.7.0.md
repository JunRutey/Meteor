# Meteor v0.7.0 · 心情日历首页与人物关联记录

## 新增

- **心情日历成为首页**：打开应用直接进入日历，标题换成应用名，右上角齿轮进入设置。
  当天卡片默认展开并默认选中今天，切换日期时卡片内容跟着变。
- **当天两个按钮按状态变化**：右侧在有日记时是「查看当天日记」（进入只读预览，右上角「修改日记」再进编辑器），
  今天没有日记时是「记录当下」，过去某天没有日记时是「补写日记」；
  左侧在当天有图时是「查看记忆图片」（只看这一天），否则是「存张记忆」，直接从系统挑图。
- **底部快捷区**：右下角圆形搜索按钮，下面一层是 AI 按钮；剩余空白区依次是「图片总览」「聊天记录」「人际关系」。
- **给人物导入文件**：人物详情页可以多选图片、文本、文档与压缩包，文件加密后存进该人物的目录，
  文本类文件同时抽出文字，用于搜索与 AI 提问。
- **记录页**：列出所有已导入的文件，可以按人物筛选，支持导出为明文到系统选择的位置，以及确认后删除。
- **日记只读预览页**：从日历进入，先看排版结果，再决定要不要改。
- **关于页**：应用名与版本、运作原理、加密说明、逐版本更新日志、GitHub 仓库与打赏二维码。
- **心情新增一档**：「emm 🥺」；开心、疲倦、难过换成更贴切的表情（😆 / 🥱 / 😵‍💫）。
- **新应用图标**：自适应图标加圆形回退。

## 修复

- **日历图标导致崩溃**：图标把自身的无障碍描述读回来赋值，读取时抛异常，页面直接挂掉；改为独立参数。
- **一个坏附件拖垮整份列表**：元数据或抽出的文本损坏时，现在只跳过那一个文件，其余照常可用，
  AI 语料也不会整体失效。
- **导入链路的四个问题**：
  - 同一个文件以前被打开两次，云盘类来源第二次会失败；现在先落到缓存临时文件，只读一次。
  - 增加单文件 256 MB 上限，超限文件跳过并单独提示，不再把内存读爆。
  - 文本解码失败时回退 GB18030，GBK 编码的中文文档不再变成乱码。
  - 导入过程显示「正在导入 3/12」进度。
- **按人物筛选不生效**：记录页选了人物列表却不变，现在真正按归属筛选，并区分「这个人还没有记录」的空态。
- **附件导出没有反馈**：导出成功或失败都会在页面上提示，不再静默。
- **按天相册标题是原始日期**：从 `2026-10-31` 改为本地化日期。
- **关于页排版**：更新日志的小节层级修正，渲染时去掉 `**` 与反引号残留。
- **调试版丢失存储诊断入口**：首页删除后入口一起消失，已放回设置页。

## 变更

- 应用起点从原来的首页改为日历，原首页删除；没有入口的日记列表页一并移除。
- 设置页重排为：外观（主题、动态取色）→ 安全（应用锁）→ 日志 → 备份 → AI → 关于。
- 移除「字体大小」与「动画」两个设置项，字号与动画固定为系统默认。
- 备份提示补充说明：导出包里包含附件的明文与从中抽取的文本。
- 附件保存为分块 AES-GCM 格式（`.data.enc` / `.meta.enc` / `.text.enc`），
  另外提交了 ADR-029，提议为附件单独建记录类型。

## 已知限制

- 附件在搜索结果与 AI 语料里仍然标成「聊天」，要等 ADR-029 通过才会显示为附件。
- 导出统一按 `application/octet-stream` 写入，存到系统后可能没有原始扩展名。
- 导入单个文件上限 256 MB，并且需要等量可用的缓存空间；超限文件只提示、不导入。
- 在编辑器里给过去某天插图，图片仍按写入时间归到当天。
- 人物详情页只能导出，不能删除；删除入口在「记录」页。
- 「聊天记录」入口目前展示的是导入文件清单，AI 对话历史还没有独立入口。
- 附件索引只在内存里重建，应用重启后第一次搜索要重新读一遍密文侧车。
