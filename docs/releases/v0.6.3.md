# Meteor v0.6.3 · AI 流式回答与过程可见

## 新增

- **流式输出**：对话请求改为 SSE（`stream: true` + `stream_options.include_usage`），
  回答逐字出现，不再等整段返回；结束时的 `usage` 仍会统计并显示 tokens / tok/s / 缓存命中率。
- **思考过程可见**：开启 DeepSeek 思考档位后，`reasoning_content` 实时显示在可折叠的
  「思考过程」区域；关闭思考档位时该区域不出现。
- **工具链可见**：Agent 每一次工具调用都会显示工具名、参数摘要与执行状态（… / ✓），
  最多 6 步的过程都能看到，而不是只有一个「思考中」。
- **自动滚动**：聊天列表跟随新消息与流式片段自动滚到底部；
  切换技能/人物仍固定在顶部，不受滚动影响。

## 变更

- `AiModule` 增加带默认实现的 `chatStreaming(request, listener)`；不支持流的实现会自动
  回退为一次性返回，接口保持兼容。
- 修正 `AiModule` 注释里「聊天只在内存」的过时描述（v0.6.2 起历史已加密落盘）。

## 已知限制

- 兼容接口如果不支持 SSE，`completeStream` 会退化为一次整段输出（界面仍可正常显示）。
- 思考过程只在提供商返回 `reasoning_content` 且开启了思考档位时出现。
- 流式过程中点「清空」会清空当前会话，正在返回的内容仍可能追加为一条新回答。
- 自动滚动在流式输出时始终跟到底部；回看旧消息时建议先发完再往上翻。
