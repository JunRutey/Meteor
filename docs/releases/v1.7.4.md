# Meteor v1.7.4 · 设置更安静，状态栏隐藏得更彻底

v1.7.4 做四件小事：修掉更新弹窗里的 `%1$s`、把更新校验再收紧一层、让隐藏状态栏后的
顶部真正和页面连成一体，以及把设置页收成更少的首屏条目。

## 修复

- **更新弹窗正文的 `%1$s`**：确认弹窗的说明文字忘记传入版本号，直接显示了格式化占位符；
  现在显示实际版本。
- **隐藏状态栏后的顶部缝隙**：之前状态栏隐藏了，但根部仍按状态栏高度留白，于是顶部出现
  一条白带；抽屉又从这个位置开始画阴影和圆角，形成明显的色差与接缝。现在隐藏状态栏时
  不再为顶部状态栏预留 inset，内容从屏幕最顶端开始绘制，抽屉与页面背景连成一块。
- **更新校验更严格**：在原有官方 SHA-256 校验之外，再检查下载的 APK 包名与签名证书是否与
  当前安装一致；来自镜像的错误包或换签名包会在安装前被拒绝。

## 变更

- **设置 → 外观**：原来的「暗色模式」改名为「主题」，不再在页面上铺三个大按钮；点击主题行
  弹出选择块（跟随系统 / 深色 / 浅色），选完即生效。
- **设置 → 外观 → 更多外观设置**：动态取色、界面动画、隐藏状态栏收进二级页面。
- **设置 → 媒体**：文件选择器同样改为点击后弹出选择块（内置 / 系统），不再占用整行三个按钮。
- **设置 → 通知**：首屏只保留通知总开关与「更多通知设置」入口；日记提醒、问题提醒、
  更新下载通知以及权限提示都移到二级页面。
- **侧边栏**：「设置」固定在侧边栏底部，不随上方功能列表滚动，也不会因为增减项目而移动。
- **设置 → 外观 → 自定义侧边栏**：可以勾选显示哪些功能，并用上移 / 下移调整顺序；隐藏功能
  不会被删除，重新打开后仍回到原来的位置。

## 已知限制

- 隐藏状态栏后内容会绘制到屏幕最顶端；带刘海或挖孔的设备上，顶部内容会更靠近前摄开孔，
  这是沉浸式显示的正常代价。从屏幕顶部下滑仍可临时唤出状态栏。
- 更新时的签名校验要求下载包与当前安装使用同一证书；自行重签名的安装包无法通过此检查，
  需要先卸载或手动安装。
- 设置二级页面没有新增自动化 UI 测试；选择块、侧边栏排序与二级页入口的导航由 CI 编译与 Lint 覆盖。
- 侧边栏自定义偏好会进入设置备份快照；换机恢复后沿用同一套显示与排序。
- AI 未启用时，即使「AI 对话」在自定义列表里处于开启状态，侧边栏也不会显示它。
- 本次不改变档案数据格式，也不修改备份、密钥或通知渠道设置。
