# Meteor v0.3.0

首次公开可用的完整版本，包含从加密存储到搜索、日历的全部基础能力。

## 新增

**加密日记**
- Android Keystore 生成设备绑定的 AES-256 密钥，正文整体 AES-256-GCM 加密
- 写入时自动附加 `meteor-sig` 时间水印，读取后剥离，正文不显示
- 编辑页在日期下方以元信息形式展示「记录于 …」
- 日记列表按日期倒序，读取失败不会影响其他记录

**全文搜索**
- SQLite FTS 索引，支持中文 bigram 分词
- 运行时自动探测后端：FTS5 → FTS4 → 纯 LIKE 扫描，设备不支持 FTS5 也不会失效
- 保存日记即增量更新索引；启动时全量重建作为兜底，失败按指数退避
- 搜索界面 250ms 防抖，结果按命中词数排序，点击直接跳到当天日记

**心情日历**
- 按月展示，每日格子显示心情 emoji，今天有底色，选中态高亮
- 点选某天弹出卡片：当前心情、六种心情选择器、跳转当天日记
- 心情以独立加密记录存放，不进入明文 frontmatter

**备份**
- 明文 zip 导出（导出前强制警告），解压后是可读的 Markdown
- 导入时逐文件用当前设备密钥重新加密，并做路径穿越校验
- 自动备份的滚动保留逻辑已实现，触发时机留待后续版本

**设置**
- 暗色模式（跟随系统 / 暗色 / 亮色）、字体大小、动画开关
- 动态取色（Android 12+ 跟随壁纸）
- 应用锁：冷启动拦截、切后台重新上锁、自动调起生物识别
- 调试日志开关、日志占用显示、导出日志到 `Download/Meteor/`

**诊断**
- debug 包内置「存储诊断」页：查看私有目录文件与原始密文、手动重建索引

## 修复

- **FTS5 不可用导致索引崩溃**：部分设备（如 Xiaomi 2406ERN9CC / API 36）的
  SQLite 未启用 FTS5，`CREATE VIRTUAL TABLE` 抛 `no such module: fts5`。
  现改为运行时探测并降级到 FTS4 或 LIKE，同时在设备上记住选择。
- **切后台返回后跳过身份验证**：会话解锁标记未复位，导致二次进入直接放行。
  现于退到后台时复位会话，并在重新进入时自动调起生物识别。
- **内容顶到状态栏**：targetSdk 35 强制边到边，已补齐系统栏内边距。
- **自动备份开关无效**：功能尚未实现，开关已隐藏，避免误导。

## 架构

- R3 可插拔：`:core-index` 可整体从构建中移除，CI 有独立任务验证
- 依赖方向由 CI 强制校验，禁止成环与反向依赖
- 新增 ADR-014 ~ ADR-017，记录人物目录、分词方案、FTS 降级、心情存储等决策

## 升级说明

- 从 v0.1.0 升级会重建索引（索引是派生缓存，不影响任何数据）
- 旧版本写入的日记完全兼容，无需迁移

## 已知限制

- 富文本编辑器尚未完成（v0.4）
- 图片只能插入与存储，预览中显示为占位符
- 自动备份仅手动触发
