# Meteor v0.9.0 · 生辰页、首次启动引导与自动更新

## 新增

- **生辰页**：首页新增「生辰」标签，显示你已经活了多久、实时年龄、公历与农历生日，以及距下次生日的倒计时。
  农历按 Android 自带的 ICU 中国日历换算，闰月在当年不存在时会回退到同一个月；
  公历 2 月 29 日出生的人在平年按 2 月 28 日过生日。
- **首次启动引导**：介绍功能与隐私条款，并可选授予通知权限。出生日期可以跳过，
  之后在「设置 → 个人资料 → 出生日期」里修改；已经有档案的老版本用户升级时不会看到引导。
- **自动检查更新**：默认开启。启动时向 GitHub 查询最新正式 Release，发现新版本后在后台下载，
  通知栏显示实时下载进度；下载完成后到「设置 → 应用更新」安装。
  安装由 Android 系统安装器处理，需要允许「安装未知来源应用」并确认。

## 修复

- **生辰页切换标签后停更**：切到「日记」再切回来，倒计时不再冻结在切走的那一刻。
- **更新安装入口**：改用系统安装器的标准入口（不再使用已废弃的 `ACTION_INSTALL_PACKAGE`），
  并在安装前校验 APK 文件头，避免把损坏或未下载完的文件交给安装器。
- **农历月份下拉框**：标题不再显示 `%1$d月` 这样的格式占位符。

## 变更

- 下载的更新会复用已经缓存的文件，并清理旧版本，不会每次启动都重新下载几 MB。
- 生辰页配色跟随应用主题：深色是夜空，浅色是晨空，与页头和标签栏保持一致。
- 年龄、生日倒计时与生日本身都在本机计算；出生日期以独立 AES-GCM 密文保存，
  不进入日记、档案或 AI 请求，也不在明文备份里。

## 已知限制

- 更新只认 GitHub 正式 Release；调试包签名不同，因此不会自动检查更新，也不会尝试安装正式包。
- 安装更新仍需允许「安装未知来源应用」，并由系统安装器确认；部分设备或安全软件会拦截。
- 农历换算依赖设备自带的 ICU 日历数据，个别旧系统可能缺少闰月信息。
- 生辰页的年龄按平均年长（365.2425 天）计算，和「周岁」的整数说法略有差异。
- 出生日期只保存在本机、不参与备份，换机恢复后需要重新设置。
