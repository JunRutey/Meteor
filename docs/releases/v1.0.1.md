# Meteor v1.0.1 · 出生日期改用滚轮选择，关于页与导航动画统一

v1.0.1 是一次体验收尾：出生日期的公历与农历都换成滚轮选择，「关于 / 打赏 / 更新日志」
三页统一为卡片式布局，主页面之间的切换动画改成共享的淡入淡出。本版没有数据格式变更，
旧日记、备份、人物档案与已保存的出生日期继续可用。

## 新增

- **出生日期滚轮选择器**：公历与农历都改为「年 / 月 / 日」三列滚轮，上下滑动选择，
  也可以直接点按某一项跳转；公历不再弹出系统日期对话框。选择结果实时显示在上方按钮里，
  滚轮停稳后才生效，拖动过程中不会反复触发换算。年、月、日互相约束：不能选到未来，
  切换月份或年份时日期会自动收敛到合法范围（例如 2 月不会停在 30 日），农历还会跟随
  大小月与闰月调整；选项区可以展开收起，收起后页面留给保存按钮。
- **关于页重做**：关于、打赏、更新日志三页统一为「返回箭头 + 页面标题 + 圆角卡片正文」，
  返回按钮换成与日历、搜索一致的手绘图标，正文在卡片内独立滚动；打赏码按宽度等比展示，
  图片缺失时显示说明文案而不是留一片空白。

## 修复

- 本版没有修复。

## 变更

- **导航动画统一**：设置、搜索、相册、对话、人物与 AI 等主页面之间改用共享的淡入淡出
  （fade-through）过渡，只有设置里的二级页面（AI 设置、用量统计、出生日期等）保留横向
  滑动；进出场时长统一并略微放慢，不再出现「有的页面滑、有的页面淡入」的割裂感。
- **出生日期默认日历**：首次进入出生日期设置时默认停在「农历」，以前默认「公历」；
  已有出生日期的用户仍按原日历打开。保存依然要求真正选过一次日期，不会把默认值直接存下。

## 已知限制

- 不改变数据格式，旧日记、备份、人物档案、AI 会话与已保存的出生日期继续可用。
- 出生日期最多选到今天，不能选未来日期；农历换算依赖设备自带 ICU 日历数据，
  个别旧系统可能缺少闰月信息。
- 滚轮一次只调整一列（年 / 月 / 日分开），没有直接输入日期的入口；切换农历年份会把
  月份与日期重置到该年第一个月、第一天。
- 关于、打赏与更新日志的正文来自应用内置的 Markdown 与图片资源，应用内不能编辑；
  打赏码文件缺失时只显示说明文字。
- 自动更新只认 GitHub 正式 Release；开始下载由应用在启动时完成，但安装仍需允许
  「安装未知来源应用」并由系统安装器确认，部分设备或安全软件会拦截。
