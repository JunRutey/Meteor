# Meteor v1.0.0 · 全新 AI 对话、人物档案管理与 DeepSeek 收敛

v1.0 把 AI 对话从「能用」打磨成完整工作区：界面按 DeepSeek 的布局重做，回答可以朗读，
用量有了独立统计页；人际关系补上了一直缺的删除入口与自定义标签；AI 接入则收敛到官方
DeepSeek。数据格式只新增了可选的用量字段与 `tags:` 头，旧日记、备份和人物档案继续可用。

## 新增

- **AI 对话界面重做**：顶部显示当前会话标题，点标题打开「对话记录」底部面板，
  可新建、切换、重命名、删除会话；右上角保留新建与「对话设置」。空状态改为一句问候、
  一段说明和三条示例提问；用户消息靠右、回答靠左，工具与思考过程折叠在回答上方；
  输入框改为圆角卡片，模式切换、附件和发送按钮集中在底部。聊天只在停留于底部时自动跟随，
  向上翻看历史时不会被流式内容拽回去，回到底部或点「回到最新消息」后恢复跟随。
- **对话内设置面板**：技能、对话对象、数字人格状态、思考强度、AI 设置入口与用量统计
  集中在一个底部面板里；切换技能或对话对象时会自动切到对应作用域的会话。
- **朗读回答**：每条回答下方新增朗读按钮，调用 DeepSeek 语音合成后在本机播放；
  可在设置中选择「海星（女声）」或「暗潮（男声）」。播放中按钮变为停止；
  切换会话、编辑提问、重新生成或发送新问题时会自动停止上一段朗读。
- **AI 设置独立成页**：主设置页只保留 AI 总开关、AI 设置入口和用量卡片；模型、思考强度、
  朗读音色、API Key、连接测试与写权限移到独立页面。页面顶部提供 DeepSeek 官方开放平台
  入口与「获取 DS API」引导。
- **累计用量统计**：新增「用量统计」页，显示累计 tokens、对话请求次数、累计用时与
  缓存命中率；每条回答仍显示单次耗时、tokens、tok/s 与缓存命中，输入框上方显示本次累计。
  累计数据保存在本机，仅统计 AI 对话请求。
- **人物档案删除**：人物详情页右上角「更多」菜单新增「删除人物」，删除前二次确认，
  文案明确说明只删除该人物的称呼、标签、备注和正文，相关日记与已导入文件不会被删除。
  删除成功后返回人物列表，并从搜索索引中移除对应档案。
- **自定义标签**：新建与编辑人物时可添加自定义标签，和「家人 / 朋友 / 绝交的朋友 /
  未分类」并列展示；最多 8 个、每个最多 24 字，自动去空白、去重，支持逗号、顿号分隔。
  标签写进 `profile.md` 的 `tags:` 头；旧档案读回为空列表，旧版本忽略这一行仍可正常读取。
- **人物详情页重做**：整页由一个列表滚动，页头、人物卡（首字母头像、称呼、关系与标签、
  一行备注）、备注、正文和相关记录都改为圆角卡片；正文再长也不会被固定页头截断。
  返回、编辑、更多等按钮改为手绘图标，与日历、搜索和 AI 页面保持一致。
- **AI 人物工具扩展**：新增 `delete_person(person_id)` 写工具，每次调用都必须在应用内
  确认，并且在「人物对话」作用域内直接拒绝；`create_person` / `update_person` 支持
  `tags` 数组，`read_person` / `list_people` 会返回标签。写工具由 6 个增加到 7 个。

## 修复

- 从设置页或人物页返回 AI 对话时，重新读取设置、API Key、模型以及联网/文件能力；
  刚保存的 Key、刚切换的模型或刚关闭的写权限会立即生效，不再停留在旧状态。
- 历史回答的 tokens、缓存命中与耗时现在随会话一起加密保存；重新打开会话或重启应用后，
  回答下方仍能看到原来的用量。
- 删除人物档案后同步移除搜索索引里的 profile 行，搜索里不再出现已删除的人物。
- AI 新建、更新或删除人物成功后也会刷新搜索索引；不必等到下次启动重建才能搜到新档案。
- 编辑提问、重新生成、切换会话、新建对话或清空对话时，正在播放的朗读会一并停止，
  不会出现上一个会话还在读、界面已经切走的情况。

## 变更

- **AI 提供商收敛为官方 DeepSeek**：设置中不再提供 OpenAI 预设与自定义接口地址，
  只保留官方 DeepSeek 接入、模型列表与 `deepseek-flash` 的联网/文件能力。
  升级时若检测到旧的非 DeepSeek 提供商，会在启动时重置为 DeepSeek 并清空旧的接口地址
  与模型名；已保存的 API Key 不会被删除，但需要替换成 DeepSeek 的 Key 才能继续使用。
- **主设置页简化**：AI 区只保留总开关、AI 设置入口和用量统计卡片，详细配置全部移到
  独立页面，避免设置页越滚越长。
- **写权限文案更新**：「允许新建/更新人物」现在也覆盖删除人物；删除人物与覆盖日记、
  修改人物、删除记录一样，必须在应用内核对参数并确认。
- **人物档案格式新增可选 `tags:` 行**：只增加字段，不改变目录结构、加密方式或已有字段；
  旧版本读新档案时会忽略该行，profile 其余内容照常可读，不需要迁移脚本。
- **朗读会把回答文本发送到 DeepSeek 语音接口**：语音合成是整段完成的，长回答需要等待
  合成结束才开始播放；音频只写入应用缓存，播放结束或停止后删除。
- **对话会话文件新增可选的用量字段**：旧会话读回时用量为空，不影响会话本身；
  会话仍按「技能 + 对话对象」分别加密保存。

## 已知限制

- AI 默认关闭，需要自备 DeepSeek API Key；开启前仍会提示内容会离开设备。
- 仅支持官方 DeepSeek 接口；OpenAI 与自定义兼容接口已移除，升级后需要重新配置
  DeepSeek Key。旧 Key 不会被自动删除，但用它发请求会失败。
- 联网搜索、文件输入与朗读目前只支持官方 DeepSeek 接口；联网与文件输入还要求
  `deepseek-flash`。思考档位开启时会使用深度思考搜索，可能产生额外工具调用与费用。
- 朗读会把整条回答的文本发送到 DeepSeek 语音接口，可能产生费用；长回答需要等待整段
  合成完成，不能像文字那样边生成边朗读，也不提供后台播放或锁屏控制。
- 文件默认 30 天后过期；删除会话时的远端删除是尽力而为，失败的文件会由服务端在到期后清理。
  原文件和解析结果均无法从 DeepSeek 下载。
- 累计用量只统计 AI 对话请求，不含朗读、联网搜索与文件上传；没有按天/按模型拆分，
  清除应用数据后会清零。
- 删除人物不可撤销，只删除人物档案本身，不级联删除日记、附件、图片或数字人格快照；
  日记里写过的 `meteor://person/<person_id>` 链接不会自动改写，会指向已删除的人物。
- 自定义标签最多 8 个、每个最多 24 字；旧版本会忽略 `tags:` 行，但不会破坏档案其余内容。
- 加密会话依赖设备 Keystore；换机后旧密钥不可恢复，请通过明文备份恢复档案。
- 删除人物后的搜索索引清理在应用内完成；如果绕过应用直接删除文件，索引会在下次启动
  重建时收敛。
