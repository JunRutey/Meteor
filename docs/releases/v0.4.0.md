# Meteor v0.4.0

把编辑器真正做完，并补上「人际关系只能建、不能改」和「图片插错了删不掉」两个洞。

## 新增

**Markdown 编辑器**
- 编辑区里 `**` 不再显示：选中文字点 `B`，直接看到粗体字
- 隐藏标记会让文本变短，因此实现了完整的光标映射，在粗体文字内部打字、删字都不会跳位
- 插入图片：自动压缩（最长边 1568、JPEG 80）、AES-GCM 加密、随机文件名落盘
- 插入链接：输入地址与显示文字，正文写成标准 Markdown 链接
- 预览与编辑一键切换；预览支持标题、列表、分隔线、加粗、颜色、链接下划线与**内联图片**
- 预览中显示真实图片（此前只显示「［图片］」占位符）

**图片可删除**
- 编辑区工具栏下方新增图片条：正文里引用到的图片按缩略图排列
- 每张右上角有 `×`，点击后二次确认，正文引用与加密文件一起删除
- 文件在**保存成功后**才真正删除：中途放弃编辑不会把已存记录的图片打碎

**人际关系可编辑**
- 档案详情页新增「编辑」入口，可修改称呼、关系与备注
- 备注使用与日记相同的 Markdown 编辑器：加粗、插图、插链接、预览
- 图片按人物归档到 `数字遗产/图片/<person_id>/`，不会混进自己的图片里

## 修复

- **在粗体中间打字光标乱跳**：标记隐藏但偏移映射缺失，光标位置与显示位置对不上
- **格式化导致崩溃**：隐藏标记后文本长度变短，Compose 因长度不一致直接抛异常
- **先点加粗再输入无效**：光标未落在标记中间
- **插入链接/图片后正文丢失**：追加时基于已保存的旧正文，而不是屏幕上正在编辑的内容
- **工具栏按钮被挤出屏幕**：横向滚动把「图片」推到看不见的位置，改为固定一行
- **预览图片必须切换一次才出现**：图片缓存变更没有进入 UI 状态

## 变更

- **颜色与斜体下线**（ADR-019）。颜色需要非标准 `<span>` 标记且只有三色，
  中文也没有真正的斜体字形。工具栏从两行合并为一行，只剩 `B`、链接、图片、预览。
- 已写下的颜色/斜体标记**不迁移**：预览仍然正常渲染，编辑区按原文显示，可手动删除。
  这样不会留下「看不见也删不掉」的样式。

## 升级说明

- 数据格式没有任何变化，旧日记、旧档案、旧图片全部照常读取
- 索引无需重建

## 已知限制

- 图片删除没有引用计数：若把同一张图的语法手工复制到多处，删一处会让另一处失效
- 人物详情页的「相关记录」仍为空——还没有入口创建归属于某人的记录（v0.6）
- 表格、代码块、任务列表仍未支持
- 自动备份仅手动触发
