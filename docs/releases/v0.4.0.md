# Meteor v0.4.0

把编辑器做完、并对齐到真正需要的能力；补上三个洞：人际关系改不了、图片删不掉、
相册看不出日期。

## 新增

**编辑器（图片 + 链接 + 预览）**
- 插入图片：自动压缩（最长边 1568、JPEG 80）、AES-GCM 加密、随机文件名落盘
- 插入链接：输入地址与显示文字，正文写标准 Markdown
- 编辑区下方是**图片条**：正文引用到的图片显示真实缩略图，每张右上角 `×` 可删除
- 预览一键切换：标题、列表、分隔线、加粗、颜色、链接下划线与**内联图片**

**图片可删除**
- 删图片时先移除正文引用，**保存成功后**才删除加密文件——
  中途放弃编辑不会把已存记录的图打碎

**人物档案可编辑**
- 详情页可改称呼、关系、备注；备注区有独立的「添加／编辑备注」入口
- 备注是 Markdown：加粗、插图、插链接、预览，详情页直接渲染效果
- 按人物归档到 `数字遗产/图片/<person_id>/`

**人物档案拆成「备注」和「正文」**
- 备注是一行短提示（「大学同学」），正文是可插图的长文，两个字段各存各的
- 详情页分两段显示，各有独立编辑入口
- 旧档案里的内容会落在「正文」里——它本来就是正文；文件格式是纯增量，无需迁移

**编辑页适配键盘**
- 人物编辑页改为可滚动表单：键盘弹出不再把输入框压成一条线
- 保存按钮移进头部，不再和键盘抢底部空间

**相册按天分组**
- 一天一个日期头，下面是这天的图，3 列方形网格（同系统相册）
- **长按**任意图片进入多选，底部出现「已选 N 张 / 取消 / 删除」
- 删除前二次确认，确认文案说明「引用过它的日记会显示为图片无法显示」

**日历标记已写日记的日子**
- 底部日期卡片里，若当天有日记，日期后面画一个**绿色重叠双对勾**

## 变更

- **颜色、斜体、加粗全部下线**（ADR-019、ADR-021）。工具栏只剩「链接 / 图片 / 预览」。
  加粗曾被实现为「隐藏 `**` 的所见即所得」，但它需要一整套光标偏移映射，
  崩过也跳过错位，而收益只是观感。现在编辑区是纯文本：**看到的就是存下来的**。
- 旧记录里的 `**…**`、`*…*`、`<span>` 不做迁移：预览照常渲染，
  编辑区按字面显示，想删就删。

## 修复

- **预览里的图片一直取不到**：`meteor://image/` 前缀被当成路径的一部分，
  存储层要的是裸路径，于是只能显示「［图片］」。现在统一用裸路径。
- **图片插入后缩略图不刷新**：位图没进 UI 状态，要切换一次预览才出现。
- **相册一天重复显示多行日期**
- **人物详情页备注无法渲染图片、也没有编辑入口**

## 升级说明

- 数据格式没有任何变化，旧日记、旧档案、旧图片全部照常读取
- 索引无需重建

## 已知限制

- 相册删除**不清理正文引用**：那条日记里会显示「图片无法显示」，需手动改
- 相册一次最多加载 120 张，没有分页
- 人物的「相关记录」仍为空——还没有入口创建归属于某人的记录（v0.6）
- 表格、代码块、任务列表仍未支持
- 自动备份仅手动触发
