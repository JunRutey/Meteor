# Meteor v0.7.4 · 界面动画可开关（默认关闭）与图片链路提速

## 新增

- **界面动画开关**：设置里新增「界面动画」。打开后页面切换是淡入淡出 + 轻微横向
  滑动，返回方向相反；图库长按选中带缩放反馈；AI 页的「技能」「对话对象」选择器
  用高度展开收起；查看器大图淡入。关闭时以上全部立即呈现。
- **查看器加载反馈**：打开大图时先显示「正在解密图片…」（动画打开时是进度圈），
  解码完成再显示图片，不再先空白一下。

## 变更

- **界面动画默认关闭**：升级后动画默认是关的。此前从没手动切过这一项的用户也会
  回到「关闭」；想用动画在设置里打开一次即可，之后会记住。
- **插图改为后台处理**：日记与人物笔记插图时，压缩和加密不再占用界面线程，编辑区
  显示「正在处理图片…」，处理期间保存按钮暂时禁用。

## 修复

- **插图可能吞掉正在输入的文字**：压缩期间敲的正文会被插入前的快照覆盖；现在只把
  新图片追加到当前最新的正文，输入不再丢失。
- **图库偶尔还显示已删除的图片**：删除图片或从后台回到图库时，若正好有一次扫描
  在跑，刷新请求会被直接丢弃，网格停在旧数据；现在改为排队重扫。
- **大图内存占用**：图库缩略图按 384px、查看器按 2048px 采样解码，压缩也先采样
  再缩放，不再把整张原图读进内存。

## 已知限制

- 采样解码的倍率只能取 2 的幂（系统位图解码的限制），少数图片的缩略图会比精确
  缩放略糊一点，点开大图即按原尺寸显示。
- 动画开关只管应用内的页面切换、图库选择条、AI 选择区和查看器淡入；系统级窗口
  动画（如返回手势）仍由系统决定。
- 图片压缩仍是 JPEG，透明背景会变成白色，与上一版一致。
