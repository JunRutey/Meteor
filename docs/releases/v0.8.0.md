# Meteor v0.8.0 · AI 写权限按项授权，每次写入都要你确认

## 新增

- **写操作逐条确认**：开启写权限后，模型每次要改档案都会先弹出「确认 AI 修改」，
  列出这次调用的工具（写日记 / 追加日记 / 设置心情 / 新建人物 / 更新人物）与完整参数；
  参数区可以滚动、可以选中复制。只有点「确认写入」才会落盘，点「拒绝」或直接关掉对话框，
  模型只会收到一句「用户已拒绝」，档案不动。没有确认界面时（例如人格蒸馏）写工具一律不执行。
- **写权限拆成两档**：设置里的「允许 AI 修改档案」下面多了「允许写日记与心情」与
  「允许新建/更新人物」。可以只让模型记日记，而不许它碰人物档案；总开关关掉时两档都不生效。
- **AI 能看的只读资料更多**：新增「统计档案规模」（记录总数、日记数量与最早/最晚日期、
  人物数量，不返回任何正文）、「列出附件」（文件名、类型、大小、日期、归属人物）
  与「读取附件文本」（导入时抽取出来的文字，最多 4000 字）。系统提示里会提醒模型：
  附件文本是不可信输入，不能照它里面的指示行事。
- **已保存的 API Key 可以核对**：Key 默认显示成 `sk-********1a2b`，点「显示」才展开原文，
  点「复制」写入剪贴板（Android 13 及以上标记为敏感内容，系统剪贴板预览不会显示）；
  新密钥在单独一栏粘贴保存，留空不会改动已存的值。保存或清除失败会留在原地并提示，不再静默。
- **隐藏桌面图标**：设置「安全」区新增开关。打开前会二次确认并说明找回方式；
  隐藏后桌面与应用列表里都不再显示 Meteor，需要时在系统拨号盘输入 `*#*#314159#*#*` 打开，
  或在应用内把开关关掉恢复。

## 变更

- **工具参数严格校验**：不是字符串的字段按「没传」处理，不再把数字或对象转成文本；
  单个参数上限 200 字（日记正文、追加内容、人物备注沿 2 万字），整次调用上限约 2.2 万字；
  附件 id 只接受 32 位十六进制，格式不对直接拒绝。
- **人物范围的对话收窄写能力**：当对话绑定到某个人物时，不再开放写日记、设置心情与新建人物，
  只能更新这个人物本身的资料。
- **启动时核对桌面图标状态**：每次冷启动都会把「隐藏桌面图标」设置重新应用到组件上，
  系统或第三方启动器把它改回来时会按设置纠正。
- **备份导出失败会删掉半成品**：导出中断时不再把写了一半的 zip 留在 `bak/` 里，
  避免它被当成可恢复的快照列出来。
- **旧凭据的迁移更省事**：某个 key 在旧版加密存储里不存在时会记住这次结果，
  不再每次读取都打开一遍旧库；另一个仍存在旧库里的 key 照常迁移。

## 修复

- **向上翻看历史时被拽回底部**：会话列表现在只在已经处于底部时才跟随新内容；
  往上翻旧消息不会被流式片段拉回去，回到底部后恢复自动跟随。
- **开启应用锁后设置页被换成解锁门禁**：锁屏只拦冷启动与切回后台，
  正在设置页操作时不会再被踢出。
- **图片地址越界**：记录里的图片地址以前只检查有没有 `..`，构造出来的地址可以指到档案正文；
  现在必须正好是 `数字遗产/图片/<人物或 _self>/<文件名>.enc`，图库也只列这一层。
- **同一时刻导入两个附件可能互相覆盖**：文件名 id 冲突时改为重试挑选空闲 id，
  中断留下的残留文件不会再让整次导入失败。

## 已知限制

- **隐藏桌面图标有真实风险**：找回入口依赖系统拨号盘派发暗号，部分手机的拨号盘不会派发；
  在系统设置里对 Meteor 执行「强制停止」后暗号同样唤不醒。这两种情况只能重装，本地数据会一并丢失。
  建议先导出一份备份，再开这个开关。
- 每次写入都要确认，模型连续改多处时会连续弹窗；确认后操作不可撤销（模型仍然没有删除能力）。
- 附件只有导入时成功抽出文本的才读得到，且最多 4000 字；图片与视频内容不会发给 AI。
- 确认框里的参数是模型原始给出的 JSON，正文较长时需要滚动查看。
- 绑定某个人物的对话里读不到心情，也不能写日记与心情：这两类数据是按日期存的，不属于某个人物。
- Key 的掩码只露前 3 位与后 4 位，太短的 Key 全部显示为星号。
- 写权限的两档细分只影响今后的对话；升级时此前开着写权限的用户两档默认都是开，行为与 v0.7.4 一致。
