# Meteor v0.9.3 · 雾蓝配色与更顺滑的设置页转场

## 新增

- 本版没有新增功能，集中修正 v0.9.2 的配色偏差并优化设置页转场。

## 修复

- **主色与预期不符**：v0.9.2 把默认主题改成了苔绿，但预期是淡蓝色。
  现在把主色、按钮、选中态、卡片与背景里的绿色调统一换成雾蓝：
  浅色主题偏晨雾蓝，深色主题偏夜空蓝。两套主题的文字与容器对比度也都重新核对过。
- **设置页转场生硬**：v0.9.2 的设置页沿用普通页面的横向滑动，
  与它「覆盖在当前标签上」的层级不符。现在改为淡入淡出加轻微缩放。

## 变更

- **设置页转场**：进入时 220ms 淡入，并从 97% 放大到 100%；
  退出时 120ms 淡出。从设置返回时底层页面同步淡入，不再从屏幕边缘横向滑入；
  关闭应用动画时仍然直接切换。
- **配色细节**：浅色主题主色 `#426989`、按钮容器 `#D6E8F7`；
  深色主题主色 `#A9C9E6`、按钮容器 `#304B63`。
  次级色、背景、表面与描边同步转为蓝灰。
  日历中「当天已有日记」的双勾仍是绿色，它是状态标记，不是按钮。
- **动态取色**：默认仍关闭；在「设置 → 外观」开启 Material You 后会跟随壁纸，
  不再显示雾蓝。

## 已知限制

- 雾蓝是固定色板，不跟随壁纸；需要跟随壁纸请在「设置 → 外观」开启动态取色。
- 本次只调整了根设置页的转场；设置里的子页面（出生日期、关于、诊断等）
  仍使用普通的前进 / 返回滑动。
- 转场使用 Compose 动画；系统「动画时长」缩放到关闭时可能直接切换。
- 日历双勾保持绿色是有意为之，避免与「已写日记」的状态语义脱节。
