# Meteor v1.5.0 · 相册支持视频与音频

v1.5.0 把「图片总览」变成真正的**相册**：除图片外，现在也能存放和播放视频与音频，
编辑器与人物档案同步支持。记录页与相册合并成一个总入口，排序可以按源数据（如照片拍摄时间）
或按存入日期。本版**不改变档案数据格式**：旧日记、旧图片、人物档案、备份与 AI 会话继续可用。

## 新增

**相册**

- 「图片总览」更名为「相册」，除图片外支持**视频**与**音频**
- 网格上有类型角标与视频时长；顶部可筛选「全部 / 图片 / 视频 / 音频」
- 点开即看即播：图片全屏缩放、视频全屏播放、音频带进度条播放
- 图片原有的分享与删除照旧可用，视频与音频同样支持

**排序方式（可选）**

- 新增「排序方式」开关：**按源数据排序**（照片的拍摄时间、视频录制时间）或
  **按存入日期排序**
- 默认仍是「按存入日期」，与旧版本表现一致；想看「这张照片是哪天拍的」时切到源数据排序

**应用内文件选择器**

- 插入媒体时使用应用内置的选择器，按月分组、可多选
- 选择器会保留源文件元数据（照片 EXIF 拍摄时间、视频/音频时长与尺寸），
  这也是「按源数据排序」的数据来源

**编辑器**

- 工具栏「插入」支持图片 / 视频 / 音频；插入后正文里显示为可看的图片块、
  可播的视频卡或音频卡
- 旧的图片插入与显示行为完全不变

**人际关系**

- 人物详情页新增「媒体」区，显示这个人的图片、视频与音频
- 「添加媒体」直接归档到该人物名下；点开即可查看或播放
- 人物正文里插入的媒体同样归到这个人

**记录页并入相册**

- 原来的「记录」与「相册」合并为一个总入口，内部用「相册 / 记录」两段切换：
  相册看媒体，记录看导入的文件

**备份**

- 明文备份现在也包含视频与音频，并额外写入媒体清单，换机恢复后
  **媒体编号与拍摄时间都不变**，正文里的引用不会断
- 没有媒体的旧备份结构完全不变，导入行为也不变

## 变更

- 首页入口文案由「图片」改为「相册」
- 日历页的图片入口、旧版分享链接等原有入口继续可用，会自动转到新的相册与查看器

## 技术说明

- 播放使用 AndroidX **Media3 / ExoPlayer**，EXIF 使用 **AndroidX ExifInterface**，
  视频缩略帧与时长使用系统 `MediaMetadataRetriever`
- **没有引入 FFmpeg**：ffmpeg-kit 已于 2025 年归档停止维护，且每个 ABI 会显著增大安装包；
  本版需要的播放、缩略图与元数据读取，平台 API 与 Media3 已完整覆盖（见 ADR-053）
- 新增共享模块 `:feature-media`；`core-storage` 新增 `MediaStore`、`MediaRef` 与
  `AlbumRepository`，均为增量类型，不改动既有冻结接口
- 新媒体存放在 `数字遗产/媒体/`，整份文件加密，目录只暴露随机的媒体编号

## 已知限制

- 相册按源数据排序依赖文件自带的时间信息：没有 EXIF 拍摄时间的老照片会退回按存入日期排列
- 媒体文件整份加密，因此播放视频/音频时会在应用缓存目录产生临时明文，播放结束即删除；
  应用被强行杀死时可能残留，下次进入媒体功能时自动清理
- 删除媒体是永久删除，引用过它的正文不会自动改写，对应位置显示「无法显示」
- 明文备份体积会因视频与音频明显变大，请自行妥善保管备份文件
- 旧版本客户端读新备份时，会看到一个无法识别的媒体清单文件；媒体在旧版本中不可见，
  升级后即可恢复
