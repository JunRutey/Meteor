# Meteor v1.4.0 · 图片看得见，格式点得亮

v1.4.0 把编辑器的两处老别扭修掉了。第一处：在日记或人物正文里插入图片，
编辑区不再显示一长串 `meteor://image/…` 内部路径，而是直接显示图片本身，
并且可以给每张图片写一句描述。第二处：加粗和彩色字体回到工具栏，
但这次是**开关**——点一下亮起，此后输入的文字就是粗体或选定颜色，再点一下结束；
编辑区把 `**` 与 `<span>` 这类标记藏起来，直接按最终样子显示。

AI 回复里裸露的星号也一并修掉：回复现在按 Markdown 渲染标题、列表、
粗体与代码。本版不改变档案数据格式。

## 新增

- **图片直接显示**：日记与人物正文里插入的图片直接显示为图片本身，不再显示
  内部路径；点图片进入查看器，右上角 × 删除。
- **图片描述**：每张图片下方可以写一句说明（例如「毕业那天的合影」），
  编辑区与预览都会显示。描述写入 Markdown 的 alt 文本，明文备份、搜索索引
  与 AI 读取都能看到。
- **加粗开关**：点工具栏的 `B`，按钮点亮；此后输入的文字直接是粗体，
  再点一次结束。已有选中文字时点它，会立即把那一段变粗。
- **彩色字体开关**：点颜色按钮展开色板，选中某色后图标变成该色的实心点；
  此后输入的文字就是该颜色，再点一次结束。换色直接替换，不会叠加两层。
- **AI 回复按 Markdown 渲染**：标题、列表、分隔线、粗体、行内代码与链接
  都渲染成实际样式，不再让星号和井号裸露在正文里。

## 修复

- 修复插入图片后编辑区出现一长串不可读路径、容易被误删或改坏的问题。
- 修复 AI 回复里 `**`、`###`、`-` 等 Markdown 标记原样显示、影响阅读的问题。
- 修复光标停在隐藏标记附近时可能跳位的问题（隐藏字符配有完整的光标映射，
  并针对映射边界单独写了测试）。

## 变更

- **正文按块渲染**：正文里独立成行的图片引用变成图片卡片，其余文字仍是普通
  输入框；打开旧记录不会改写文件内容。
- **格式按钮改为开关**：从「选中文字再点按钮」变成「先开格式再打字」，
  两种习惯都支持——有选区时点按钮会直接包裹选中的文字。
- **标记隐藏**：编辑区的 `**` 与 `<span style="color:…">` 不再显示，
  被包裹的文字直接按粗体或彩色显示。存进文件的仍然是同样的 Markdown，
  备份、检索、AI 读取与旧版本打开都不受影响。
- **行内引用与远程图片保持原样**：`看图 ![](…) 不错` 这种和文字写在同一行的
  引用、以及 `https://` 这类无法解密的图片，仍按文本显示，可手动编辑。

## 已知限制

- 不改变档案数据格式；旧日记、备份、人物档案、AI 会话与已保存的出生日期继续可用。
- 图片描述只能是单段文字，换行与方括号会被替换；不支持图片缩放与自由图注位置。
- 图片卡片的显示高度由图片自身比例决定，超长竖图会占较多屏幕空间。
- 格式开关作用在当前文本块内；中间隔着图片块时，新块不会自动接续上一块的格式。
- 若文本块内出现未闭合的颜色标记，其后的文字会一直着色到块尾，关闭格式即补上闭合。
- 斜体仍只有数据支持，没有按钮：中文没有真正的斜体字形，倾斜合成观感较差。
- 没有单独的格式撤销栈，点错了需要手动删除标记。
