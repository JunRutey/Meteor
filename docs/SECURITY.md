## 数据安全

- 文件正文 AES-256-GCM 加密，frontmatter 仅含索引所需元数据
- 人物称呼、关系与自定义标签都在 `profile.md` 的加密内容里，目录只用随机 `person_id`
- 导入附件及提取出的文本均加密保存；附件文本索引只驻留内存，照片和视频不发送给 AI
- 密钥由 Android Keystore 生成，绑定设备，**换机后旧密钥不可恢复**
- 因此备份导出为明文 zip —— 这是换机恢复的唯一路径，请妥善保管
- 应用默认 `allowBackup=false`，不参与系统云备份
- 从图片查看器分享时，解密后的图片会写入应用私有 `cacheDir/share/`，仅供系统分享面板读取；
  该缓存最长保留约 24 小时，下一次分享会清理更早文件，系统清理缓存时也会删除，且不参与备份
- 出生日期以 AES-256-GCM 密文保存在档案目录内，会随明文备份一起导出；它不会进入日记正文或 AI 记录
- 备份还包含一份加密的设置快照（主题、通知、人物自定义标签、AI 非密钥配置、累计用量、引导状态）；
  导入成功后恢复。API Key、应用锁、禁止截屏与 AI 同意不进入备份
- **应用锁是进入应用前的身份门禁，不是加密边界**：文件密钥不绑定生物识别，应用锁只决定
  谁能看到界面。解锁走系统验证，优先生物识别（指纹、人脸、虹膜），没有可用生物识别时
  回退到锁屏 PIN、图案或密码；设备完全没有锁屏也没有生物识别时，应用锁无法开启，已开启
  的会给出一次需要确认的关闭入口，避免档案被永久锁死。

## 更新检查与隐私

设置里的自动检查默认开启，每次启动时向 GitHub 查询最新正式 Release；发现新版本后自动在后台下载，
并在通知总开关开启时于通知栏显示实时进度（可随时关闭）。下载完成后到「设置 → 应用更新」点安装，
由 Android 系统安装器接管，可能需要允许 Meteor 安装未知来源应用，且必须由用户确认。
关闭设置项后不再自动查询，仍可手动检查。更新检查仅向 GitHub 发送版本查询请求，
不会发送日记、档案、设备内容或账号凭据。

Meteor 没有自建后端；作者不接收、不收集、不记录应用使用内容，没有埋点、崩溃上报，
也没有任何使用数据上报。AI 的累计用量只保存在本机，用于给你自己看。
