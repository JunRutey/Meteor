- **思维链回传**：带工具的思考请求会把 `reasoning_content` 回传，符合 DeepSeek 的工具调用要求。

  （与档案文件同一个 Keystore 别名）加密后存成 Base64 密文；旧版

## v0.6.0

### 新增

- **可开关的联网 AI**：设置页新增「AI 与数字人格」区域。默认开启入口但**不会发出任何请求**；

- **技能机制**：人格蒸馏 / 人格对话 / 档案问答以 Markdown 技能包内置（frontmatter + prompt），
  设置里可查看当前提供商与模型；格式参考并致谢 MIT 许可的 nuwa-skill、distilly、ex-skill。
- **本机检索保留**：不联网也能用关键词在自己的档案里检索，作为 AI 关闭时的降级能力与
  模型可调用的检索工具。

### 修复

- 本版本没有改动既有功能的行为。

### 变更

- 应用新增 `INTERNET` 权限，但只有 AI 开启且用户确认后才会发起请求，且只发往用户配置的接口。
- AI 的所有文案都明确标注数据流向与「作者不收集 / 不记录 / 不跟踪」。
- 设置项 `aiEnabled` 默认开启入口，`aiConsentAccepted` 默认为否；未同意、未配置 Key 时 AI 页面只显示引导。

### 隐私承诺

- Meteor 没有后端，作者不接收、不收集、不记录任何内容，没有埋点与崩溃上报。
- 内容只通过 HTTPS 直接发往你选择的 AI 提供商，受该提供商隐私条款约束。
- API Key 存于 Keystore 派生的 EncryptedSharedPreferences，不进 DataStore、不进备份、不写日志。
- 聊天记录不落盘；日志只记事件与错误码。
- 模型只能读档案（六个只读工具），唯一的写操作是确认后的人格档案落盘。

### 已知限制

- 需要自备 API Key 并承担调用费用；不配置 Key 时 AI 功能不可用，其余功能不受影响。
- 依赖提供商的 OpenAI 兼容 `/chat/completions` 与工具调用（function calling）能力；
  不支持工具调用的接口无法完成人格蒸馏与多轮查档。
- 人格蒸馏质量取决于档案里的材料与所选模型；材料不足时会标注「信息不足」而不是编造。
- 每次蒸馏/提问的上下文由应用挑选并截断（单条记录、工具结果均有上限），

- 真实联网行为无法在 CI 中验证；CI 覆盖编译、协议编解码、工具循环边界、技能解析与同意门控。

- 底部日期卡片里，若当天有日记，日期后面画一个**绿色重叠双对勾**

### 变更

- **颜色、斜体、加粗全部下线**（ADR-019、ADR-021）。工具栏只剩「链接 / 图片 / 预览」。
  加粗曾被实现为「隐藏 `**` 的所见即所得」，但它需要一整套光标偏移映射，
  崩过也跳过错位，而收益只是观感。现在编辑区是纯文本：**看到的就是存下来的**。
- 旧记录里的 `**…**`、`*…*`、`<span>` 不做迁移：预览照常渲染，
  编辑区按字面显示，想删就删。

### 修复

- **预览里的图片一直取不到**：`meteor://image/` 前缀被当成路径的一部分，
  存储层要的是裸路径，于是只能显示「［图片］」。现在统一用裸路径。
- **图片插入后缩略图不刷新**：位图没进 UI 状态，要切换一次预览才出现。
- **相册一天重复显示多行日期**
- **人物详情页备注无法渲染图片、也没有编辑入口**
- **键盘弹起整个窗口被顶飞**：标题、「保存」、称呼、关系一起滑出屏幕，
  页面还"咚"地跳一下。现在 inset 统一在根部处理，边框不再平移，
  只有正文编辑器随键盘伸缩
- **状态栏图标在浅色背景上几乎看不见**（白色图标画在米白背景上），
  现在跟随应用主题切换深/浅图标

### 升级说明

- 数据格式没有任何变化，旧日记、旧档案、旧图片全部照常读取
- 索引无需重建

### 已知限制

- 相册删除**不清理正文引用**：那条日记里会显示「图片无法显示」，需手动改
- 相册一次最多加载 120 张，没有分页
- 人物的「相关记录」仍为空——还没有入口创建归属于某人的记录（v0.6）
- 表格、代码块、任务列表仍未支持
- 自动备份仅手动触发

## v0.3.0

首次公开可用的完整版本，包含从加密存储到搜索、日历的全部基础能力。

### 新增

**加密日记**
- Android Keystore 生成设备绑定的 AES-256 密钥，正文整体 AES-256-GCM 加密
- 写入时自动附加 `meteor-sig` 时间水印，读取后剥离，正文不显示
- 编辑页在日期下方以元信息形式展示「记录于 …」
- 日记列表按日期倒序，读取失败不会影响其他记录

**全文搜索**
- SQLite FTS 索引，支持中文 bigram 分词
- 运行时自动探测后端：FTS5 → FTS4 → 纯 LIKE 扫描，设备不支持 FTS5 也不会失效
- 保存日记即增量更新索引；启动时全量重建作为兜底，失败按指数退避
- 搜索界面 250ms 防抖，结果按命中词数排序，点击直接跳到当天日记

**心情日历**
- 按月展示，每日格子显示心情 emoji，今天有底色，选中态高亮
- 点选某天弹出卡片：当前心情、六种心情选择器、跳转当天日记
- 心情以独立加密记录存放，不进入明文 frontmatter

**备份**
- 明文 zip 导出（导出前强制警告），解压后是可读的 Markdown
- 导入时逐文件用当前设备密钥重新加密，并做路径穿越校验
- 自动备份的滚动保留逻辑已实现，触发时机留待后续版本

**设置**
- 暗色模式（跟随系统 / 暗色 / 亮色）、字体大小、动画开关
- 动态取色（Android 12+ 跟随壁纸）
- 应用锁：冷启动拦截、切后台重新上锁、自动调起生物识别
- 调试日志开关、日志占用显示、导出日志到 `Download/Meteor/`

**诊断**
- debug 包内置「存储诊断」页：查看私有目录文件与原始密文、手动重建索引

### 修复

- **FTS5 不可用导致索引崩溃**：部分设备（如 Xiaomi 2406ERN9CC / API 36）的
  SQLite 未启用 FTS5，`CREATE VIRTUAL TABLE` 抛 `no such module: fts5`。
  现改为运行时探测并降级到 FTS4 或 LIKE，同时在设备上记住选择。
- **切后台返回后跳过身份验证**：会话解锁标记未复位，导致二次进入直接放行。
  现于退到后台时复位会话，并在重新进入时自动调起生物识别。
- **内容顶到状态栏**：targetSdk 35 强制边到边，已补齐系统栏内边距。
- **自动备份开关无效**：功能尚未实现，开关已隐藏，避免误导。

### 架构

- R3 可插拔：`:core-index` 可整体从构建中移除，CI 有独立任务验证
- 依赖方向由 CI 强制校验，禁止成环与反向依赖
- 新增 ADR-014 ~ ADR-017，记录人物目录、分词方案、FTS 降级、心情存储等决策

### 升级说明

- 从 v0.1.0 升级会重建索引（索引是派生缓存，不影响任何数据）
- 旧版本写入的日记完全兼容，无需迁移

### 已知限制

- 富文本编辑器尚未完成（v0.4）
- 图片只能插入与存储，预览中显示为占位符
- 自动备份仅手动触发
