# Meteor 是怎么运作的

Meteor 是一个本地优先的个人记忆档案：日记、心情、人物档案、聊天记录、图片，
全部以**加密文件**的形式存放在应用私有目录里。没有账号，没有服务器，没有同步。

## 数据就是文件

每一条记录都是一个 Markdown 文件，带一段只有五个字段的元数据头
（加密标记、人物 ID、类型、时间戳、来源）。正文在落盘前整体加密，
文件名和目录名只包含索引所需的信息，不含任何内容。

- 文件是唯一真相源，随时可以导出成可读的 Markdown
- 元数据头保持明文，是为了目录路由和全文索引能工作
- 索引是缓存，删掉也能重建

## 加密

- 每个文件独立使用 AES-256-GCM 加密，带随机 IV 与完整性校验
- 密钥由 Android Keystore 生成，绑定这台设备，不可导出、不可迁移
- 应用锁开启后调用系统生物识别；离开前台会重新上锁
- 应用不参与系统云备份（`allowBackup=false`）

因为密钥绑设备，**换机后旧密钥无法恢复**，所以备份导出的是明文 zip ——
这是换机恢复的唯一路径，请妥善保管。

## 唯一的联网功能

AI 是这里唯一会联网的功能，默认关闭，随时可以关掉。开启并填好你自己的 API Key 后，
你的提问与被选中的少量档案片段会通过 HTTPS 直接发往你选择的 AI 提供商；
应用本身不与任何作者的服务器通信，没有埋点、没有崩溃上报、没有使用统计。
